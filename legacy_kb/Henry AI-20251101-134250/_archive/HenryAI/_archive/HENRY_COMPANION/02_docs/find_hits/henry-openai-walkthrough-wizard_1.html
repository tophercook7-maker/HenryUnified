Create Your OpenAI Account

Let's get you set up with OpenAI (it's free to start!)

📝 What You'll Need:
• An email address
• A phone number for verification
• About 5 minutes of your time
Go to: https://platform.openai.com
Click "Sign Up" in the top right corner
• Enter your email address
• Create a strong password
• Verify you're not a robot
• Click "Create Account"
• Check your email for a verification link
• Click the link to verify your email
• Return to the OpenAI website
⚠️ Important: Make sure to use a real email address that you check regularly. You'll need it for account recovery and important notifications.
3

Verify Your Phone Number

Secure your account with phone verification

• Enter your mobile phone number
• Choose your country code
• Click "Send Code"
• Check your phone for SMS
• Enter the 6-digit code
• Click "Verify"
💡 Pro Tip: Use your main mobile number. You'll need it for important security notifications about your API usage.
4

Get Your API Key

This is what powers Henry's brain!

• Click on your profile picture (top right)
• Select "View API keys" from the dropdown
• Or go directly to: platform.openai.com/api-keys
• Click "Create new secret key"
• Give it a name like "Henry AI"
• Click "Create secret key"
• Click the "Copy" button next to your new key
• Important: Save it somewhere safe - you can't see it again!
Your API key will appear here after you create it
🔒 Security Note: Treat your API key like a password. Never share it publicly or commit it to code repositories.
